# 🍽️ Culinary Plan - Quick Start Guide

## What is Culinary Plan?

Plan and track your food adventures together! Discover restaurants, cafes, and culinary experiences. Keep a wishlist, plan visits, and remember your favorites.

## Quick Actions

### Add a New Place
1. Click "Add Place" button
2. Enter restaurant/cafe name (required)
3. Add details: location, cuisine type, price range
4. List must-try menu items
5. Choose status: Wishlist, Planned, or Visited
6. Save!

### Mark as Visited
1. Edit the place
2. Change status to "✅ Visited"
3. Add visit date
4. Rate it (1-5 stars)
5. Mark as favorite ❤️

### Find Places
Use filter tabs:
- **🍽️ All Places** - See everything
- **✨ Wishlist** - Places to try someday
- **📅 Planned** - Scheduled visits
- **✅ Visited** - Places you've been

## Field Guide

| Field | Required | Example | Description |
|-------|----------|---------|-------------|
| **Place Name** | ✅ Yes | "Sushi Paradise" | Restaurant or cafe name |
| **Location** | No | "123 Main St, Downtown" | Address or area |
| **Cuisine Type** | No | "Japanese" | Type of food |
| **Price Range** | No | "$$$" | Budget: $, $$, $$$, $$$$ |
| **Recommended Menu** | No | "Omakase Set\nSpicy Tuna" | Must-try dishes |
| **Notes** | No | "Reservations required" | Any additional info |
| **Status** | No | "Wishlist" | Current planning status |
| **Visit Date** | No* | "2025-10-15" | *Only for visited places |
| **Rating** | No* | "5" | *Only for visited places (1-5) |

## Status Guide

### ✨ Wishlist
- Places you want to try someday
- Build your foodie bucket list
- Perfect for date ideas

### 📅 Planned
- Upcoming visits
- Reservations made
- Add notes about when/why

### ✅ Visited
- Places you've already been
- Add visit date and rating
- Remember what you ordered

## Price Range Guide

| Symbol | Meaning | Example |
|--------|---------|---------|
| $ | Budget | Fast food, casual spots ($5-15) |
| $$ | Moderate | Casual dining ($15-30) |
| $$$ | Expensive | Nice restaurants ($30-60) |
| $$$$ | Fine Dining | Special occasions ($60+) |

## Tips & Tricks

### 💡 Use Notes For:
- "Anniversary spot!"
- "Best for brunch"
- "Cash only"
- "Always crowded on weekends"
- "Parking in back"
- "Ask for window seat"

### 💡 Recommended Menu Format:
```
Spicy Tuna Roll - MUST TRY!
Dragon Roll
Miso Soup
Green Tea Ice Cream
```

### 💡 Smart Planning:
1. Add places to wishlist throughout the week
2. Move to "Planned" when booking
3. Update to "Visited" after dining
4. Mark favorites for easy reference
